# Enable GitHub Pages - Quick Guide

## You Need to Enable GitHub Pages (2 minutes)

### Steps:

1. **Go to your GitHub repository:**
   - https://github.com/zumu-g/Remembrance_app

2. **Click "Settings"** (top tab, right side)

3. **Click "Pages"** in the left sidebar

4. **Under "Source":**
   - Branch: Select **"main"**
   - Folder: Select **"/ (root)"**
   - Click **"Save"**

5. **Wait 1-2 minutes** for GitHub to deploy

6. **Your URLs will be live at:**
   - Privacy Policy: https://zumu-g.github.io/Remembrance_app/docs/privacy.html
   - Terms of Service: https://zumu-g.github.io/Remembrance_app/docs/terms.html

### Verify It's Working:

After 1-2 minutes, visit the URLs above in your browser. They should display the privacy policy and terms.

### If You Get 404 Error:

- Wait another minute (can take up to 5 minutes)
- Refresh the page
- Check that GitHub Pages is enabled in Settings → Pages

---

## ✅ Once Live:

The URLs are already updated in your app code, so you're ready to proceed with the app build!

**Next step after enabling:** Build and archive the app for App Store
